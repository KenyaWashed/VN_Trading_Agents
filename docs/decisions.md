1. **Package Layout (`src/vn_rsi/`)**: Used `hatchling` `src/` layout with Python $\ge 3.11$ type annotations (`from __future__ import annotations`), `pydantic>=2.6` schemas for constrained decoding, `pyarrow` Parquet snapshots, `scikit-learn` / `scipy` baselines & statistical tests, and `pytest` + `ruff` + `mypy`.
2. **Graceful Hardware Fallback (`configured_vram_gb: 0.0`)**: Detected that the current workstation has no NVIDIA GPU (`nvidia-smi` absent) and no running `ollama` daemon. Implemented `OpenAICompatLocalBackend` (ready out-of-the-box for `Ollama` / `vLLM` / `llama.cpp` serving `qwen3:8b-q4_K_M` on a 24 GB GPU) alongside `RuleGuidedSmallLMBackend` (a seeded, grammar-constrained $\le$8B scaffolding policy on CPU) with automatic health-probe fallback and explicit `llm_backend` provenance tagging in every JSONL log.
3. **T+2.5 EOD Holding Lock (`min_holding_bars_eod: 3`)**: Because Vietnam's `T+2.5` settlement credits shares in the afternoon session of `T+2`, an EOD rebalance engine executing at market close cannot conservatively liquidate a `T` close purchase until `T+3` close (or `T+2` afternoon). Setting `min_holding_bars_eod = 3` and `rebalance_every_days = 3` guarantees strict compliance without optimistic intraday fill assumptions.
4. **Prediction Horizon (`5` trading days in-distribution, `10` trading days OOD)**: Chosen to align naturally with `T+2.5` minimum holding periods and weekly turnover constraints after the `0.10%` statutory sell tax + `0.15%` brokerage fee.
5. **Purging & Embargo Sizing**: Set `purge_days = max(horizon + 1, 6)` and `embargo_days = 5` in `PurgedEmbargoWalkForwardSplitter`, and placed a 10+ business-day gap between `validation` end (`2024-06-28`) and `sealed_test` start (`2024-07-15`) so zero 5-day forward return labels bleed across zone boundaries.
6. **Composite Outer-Loop Selection Objective**: Defined `val_composite = val_net_sharpe + 10.0 * val_rank_ic` across 3 paired seeds (`[101, 202, 303]`). Combining after-cost Sharpe with cross-sectional Rank IC prevents the outer loop from selecting low-breadth lucky 1-stock bets that inflate Sharpe on short windows.
7. **Single-Shot Sealed Test Discipline**: Only frozen human baselines (`phase2_baselines`), the median-validation seed representative of `Agent v0` (`phase3_agent_v0`), and the single top-validation `VN-RSI v*` ensemble (`phase4_rsi`) are ever evaluated on `sealed_test`. Every access is permanently recorded in `logs/sealed_test_ledger.jsonl`, and duplicate config hashes raise `SealedTestReuseError`.
